# 時計塔の館と星の涙

スマートフォンで遊べる推理謎解きゲームです。館や山荘の部屋を歩き回って証拠を集め、謎を解いて事件の犯人を突き止めます。シナリオは複数あり、一覧から選んで遊べます。

| シナリオ               | 舞台と事件                                           | 謎の数 |
| ---------------------- | ---------------------------------------------------- | ------ |
| 時計塔の館と星の涙     | 時任伯爵の館で宝石「星の涙」が盗まれる               | 10     |
| 雪の天文台と消えた彗星 | 雪に閉ざされた山荘の天文台から彗星の写真乾板が消える | 12     |

**プレイ:** https://genzouw.github.io/clocktower-mystery/

## 遊び方

- 館の中を一人称視点の 3D で歩き回る
  - スマホ：左下のスティックで歩き、画面をドラッグして見回す
  - PC：W / S で前後、A / D で左右、← / → で向きを変える。マウスのドラッグでも見回せる
- 台座の上の物に近づいてタップすると調べられる。シナリオ 1 は、金色の輪が光っている物に謎がある。シナリオ 2 は、謎のある物を見た目では示さない。どの物も調べて、説明文を読む
- 部屋にはすべて最初から入れる。2階と地下へは、廊下の階段の扉から行ける。シナリオ 2 の観測ドームへは、客室の外階段の扉から行ける
- 謎の中には、別の謎を解くと見つかる手がかりが必要なものがある。手がかりがそろうまでは答えられない（シナリオ 1 では、3D 空間の名札に「手がかり不足」と出る）。シナリオ 2 には、前提の謎を解くまで普通の物として振る舞う物がある
- 謎を解くと証拠が「手帳」に記録される。最後の謎（犯人の指名）は、ほかの謎をすべて解くまで答えられない
- 使ったヒントの数と誤答の回数は、謎の画面・手帳・エンディングで確認できる。エンディングでは合計から探偵ランクが決まる
- 起動するとシナリオ（事件ファイル）の一覧が出る。進行状況はシナリオごとにブラウザの localStorage に保存される（シナリオ 1 は `clocktower-mystery:v1`、それ以外は `clocktower-mystery:<シナリオ ID>:v1`、最後に選んだシナリオは `clocktower-mystery:current`）

## 開発

```bash
npm ci
npm run dev        # 開発サーバー
npm test           # 謎の解が一意に決まるか・館を歩いて全部屋と全部の物に手が届くかを検証
npm run build      # dist/ に静的ファイルを出力
```

| ディレクトリ      | 内容                                                                    |
| ----------------- | ----------------------------------------------------------------------- |
| `src/game/`       | シナリオごとの謎・部屋・証拠のデータ（`scenarios/<id>/`）と進行ロジック |
| `src/components/` | 画面の部品（部屋のシーン、謎のモーダル、手帳、見取り図）                |

シナリオを足すときは、`src/game/scenarios/<id>/` に部屋（`rooms.ts`）・間取り（`layout.ts`）・謎・証拠・結末・総当たり関数と、それらを `Scenario` に組み立てる `index.ts` を置き、`src/game/scenarios/index.ts` の `SCENARIOS` に登録します。謎を追加・変更したときは、総当たり関数を `src/game/scenarios/<id>/solve.ts` に足します。共通テスト `src/game/scenarios.test.ts` が全謎で解が 1 つに決まることを検証し、総当たり関数の無い謎があると失敗します。

## デプロイ

`main` ブランチへの push（PR のマージ）で `.github/workflows/deploy.yml` が動き、ビルド結果を GitHub Pages へデプロイします。PR では `.github/workflows/ci.yml` が format・lint・型チェック・テスト・ビルドを検証します。
