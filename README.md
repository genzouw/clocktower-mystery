# 時計塔の館と星の涙

スマートフォンで遊べる推理謎解きゲームです。洋館の部屋を歩き回って証拠を集め、10 の謎を解いて宝石泥棒を突き止めます。

**プレイ:** https://genzouw.github.io/clocktower-mystery/

## 遊び方

- 館の中を一人称視点の 3D で歩き回る
  - スマホ：左下のスティックで歩き、画面をドラッグして見回す
  - PC：W / S で前後、A / D で左右、← / → で向きを変える。マウスのドラッグでも見回せる
- 台座の上の物に近づいてタップすると調べられる。金色の輪が光っている物には謎がある
- 館の部屋にはすべて最初から入れ、どの謎にも挑める。2階と地下へは廊下の階段の扉から行ける
- 謎の中には、別の謎を解くと見つかる手がかりが必要なものがある。手がかりがそろうまでは答えられない（3D 空間の名札に「手がかり不足」と出る）
- 謎を解くと証拠が「手帳」に記録される。最後の謎（犯人の指名）は、ほかの 9 問をすべて解くまで答えられない
- 使ったヒントの数と誤答の回数は、謎の画面・手帳・エンディングで確認できる。エンディングでは合計から探偵ランクが決まる
- 進行状況はブラウザの localStorage に保存される

## 開発

```bash
npm ci
npm run dev        # 開発サーバー
npm test           # 謎の解が一意に決まるか・館を歩いて全部屋と全部の物に手が届くかを検証
npm run build      # dist/ に静的ファイルを出力
```

| ディレクトリ      | 内容                                                     |
| ----------------- | -------------------------------------------------------- |
| `src/game/`       | 謎・部屋・証拠のデータと進行ロジック                     |
| `src/components/` | 画面の部品（部屋のシーン、謎のモーダル、手帳、見取り図） |

謎を追加・変更したときは `src/game/puzzles.test.ts` に総当たりの検証を足し、答えが一意に決まることを確かめます。

## デプロイ

`main` ブランチへの push（PR のマージ）で `.github/workflows/deploy.yml` が動き、ビルド結果を GitHub Pages へデプロイします。PR では `.github/workflows/ci.yml` が format・lint・型チェック・テスト・ビルドを検証します。
